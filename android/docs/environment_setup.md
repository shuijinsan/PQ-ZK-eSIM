# Android 环境配置文档
## 1. 安装 Android Studio
下载并安装 Android Studio Jellyfish 或以上版本。

## 2. 安装 NDK r26d
在 Tools → SDK Manager → SDK Tools 中勾选 NDK r26d。

## 3. 配置 CMake
安装 CMake 3.22 及以上版本。

## 4. 导入项目
打开 android/ 目录，等待 Gradle 同步完成。

## 5. 连接设备
使用 Android 9.0 以上真机，开启 USB 调试。

## 6. 编译运行
点击 Run 即可安装并启动 Demo APP。
