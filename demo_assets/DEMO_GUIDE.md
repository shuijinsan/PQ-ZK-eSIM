# PQ-ZK-eSIM 项目演示指南
## 项目整体架构
- 算法层：liboqs + Kyber-768 抗量子密码
- 后端：Python FastAPI 服务
- 终端：Android APP（eUICC + TEE 模拟）
- 前端：可视化操作界面

## 快速体验（评委版）
1. 下载 Android Demo APK（Release 中）
2. 安装并打开 APP
3. 点击「初始化」完成密钥写入
4. 点击「开始认证」执行全流程
5. 查看认证结果与日志

## 流程说明
1. 注册 → 生成公私钥对
2. 预计算 → 生成内外承诺
3. 挑战 → 服务端下发随机种子
4. 鉴权 → TEE 生物特征验证
5. 计算 → 掩码响应与计数器更新
6. 验证 → 服务端零知识验证

## 亮点
- 后量子安全
- 零知识证明
- 前向安全
- 硬件安全模拟
- 端到端可演示
