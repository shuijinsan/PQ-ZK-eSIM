# PQ-ZK-eSIM artifact requirements

## Core build
- Ubuntu 22.04 LTS (x86_64)
- gcc / g++
- CMake >= 3.22
- gcc-aarch64-linux-gnu
- qemu-user-static

## Cryptographic libraries
- OpenSSL 3.0.13
- liboqs 0.15.0

## Experiment tooling
- Python >= 3.9
- numpy
- pandas
- matplotlib

## Security estimation
- lattice-estimator commit 6019056
- SageMath as required by lattice-estimator
- fpylll

## Optional backend
- FastAPI / uvicorn
- SQLAlchemy / PyMySQL
- redis Python package
- MySQL 8.0 on localhost:3306
- Redis on localhost:6379
